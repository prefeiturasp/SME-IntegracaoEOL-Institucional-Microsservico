Cross-Domain
============

Ver :doc:`../docs/cross_domain_endpoints` para a matriz completa em Markdown.

Resumo
------

Endpoints de outros domínios são expostos como placeholders ``501`` para que o
Transition Gateway identifique a responsabilidade sem receber falso ``404``.

Domínios responsáveis:

- **Professores**: supervisores de DRE, professores por escola, funcionários
- **Alunos**: quantidade de alunos, matrículas
- **Pedagógico**: modalidades de ensino, salas, turmas
